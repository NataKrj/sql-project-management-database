# Source traceability

The portfolio package was built from the supplied project materials:

- `Modern Database Technologies.pdf` — business case, business rules, conceptual/logical model, implementation narrative, query objectives and reported outputs.
- `Project model.drawio` / `Project model.drawio.pdf` — ERD and relationship model.
- `Project tables creation.sql` — original table/constraint creation sequence.
- `Insert the data.sql` — sample records, assignments, timesheet summary rows and later schema/data updates.
- `calculations and data retrieval.sql` — source analytical SQL.
- `employee_timesheet_id.csv`, `Timesheet.csv`, `working_dates.csv` — detailed source data exports.

The repository intentionally does not include the original coursework PDF or screenshots; it presents a clean technical portfolio artifact while retaining traceability to the source implementation.
